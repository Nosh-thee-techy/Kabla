# What's next (out of License-stage scope)

- **Protect** stage: takedown / dispute pack from the same trail.
- **Earn** stage: a real BASIX marketplace listing of the ERC-721-shaped metadata.
- Load the Omega plugin for real (L1): Red Lines memory across sessions, then
  chat on Telegram / WhatsApp / USSD for feature phones (L2).
- Live extraction: a **"please confirm this clause"** check when confidence is
  low. Deterministic demo uses saved fixtures; live LLM reads can be wrong, and
  an extraction error would flow into the rules. NAL truth values `(stv f c)`
  are the planned signal (L3).
- Testnet mint only, never mainnet (L4).
- Fluent-speaker review of the Swahili templates.
- **Before-stage onboarding** (dropped for the 23:59 deadline): an artist pastes a bio or catalogue
  breakdown and ticks a consent box; handles are recorded, **never scraped**. The reader turns the text
  into profile facts (platforms, works held, stated splits), MeTTa lists the gaps, and the profile is
  sealed in the same hash-linked ledger. Wording stays "self-declared, consent-recorded", not "verified".
- **Profile / passport token**: ERC-721-shaped metadata for the profile, not only the passport.
- **Testnet smart contract**: a small non-transferable ERC-721 minted on an EVM testnet, with Verify
  showing "on-chain hash matches". Testnet only, deployer key in git-ignored `.env`.
- **Public hosting** so judges can open the app without running it locally.
- **Live reading of pasted contracts** needs an LLM key in `.env` (`KABLA_MODE=live`). Without it, pasted
  text outside the three samples gets a plain 422 message and nothing is decided.
